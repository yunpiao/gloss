# Gloss – 智能词汇标注工具

Gloss 是一个面向**语言学习者**的网页词汇标注脚本。  
它会在网页正文中为单词/词组添加 `<ruby>` 标注，不破坏排版，支持**悬停显示翻译**或**默认全部显示**，帮助你在阅读真实网页内容时顺手提升中英文水平。

## ✨ 功能特点

### 核心功能
- **智能语言检测** - 自动判断中文/英文页面
- **AI 词汇筛选** - 优先挑选学术/技术词汇、关键词、习语
- **不破坏排版** - 使用原生 `<ruby>` 标签，优雅显示

### 词汇本
- **📖 全局词汇本** - 跨页面保存所有翻译过的词汇
- **✓ 已掌握标记** - 标记已掌握的词，之后不再标注
- **📤 导出 CSV** - 导出到 Excel 进行管理
- **📥 导入 CSV** - 从 Excel 批量导入词汇
- **🗑️ 清空** - 一键清空全部词汇

### 智能缓存
- **7 天缓存** - 同一页面再次访问无需重复请求
- **自动合并** - 重新分析时新旧词汇智能合并
- **手动清除** - 可在设置中清除当前页缓存

### 黑名单
- **网站黑名单** - 排除不想标注的网站
- **通配符支持** - 如 `*.google.com`
- **一键添加** - 快速将当前网站加入黑名单

### 其他
- **最少词汇数** - 页面词汇太少时不自动标注（使用分词统计）
- **自动标注** - 可按语言设置自动开始
- **悬浮控制条** - 显示状态、还原、重新分析

## 📦 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击安装脚本（GreasyFork 链接）
3. 打开任意网页，右下角会出现 Gloss 控制条

## 🚀 使用说明

### 首次使用
1. 点击控制条的 `⚙` 打开设置
2. 填写 **API 地址**、**API Key**、**模型名称**
3. 保存设置

### 日常使用
1. 点击「开始」分析当前页面
2. 词汇会以 ruby 标注形式显示在原文上方
3. 点击「还原」可清除标注
4. 点击 ▼ 可选择「重新分析」

### 词汇本
1. 设置中点击「📖 打开词汇本」
2. 查看所有翻译过的词汇
3. 点击「✓ 掌握」标记已掌握，之后不再标注
4. 支持筛选、搜索、导入导出

## ⚙️ 配置说明

| 选项 | 说明 |
|------|------|
| API 地址 | 兼容 OpenAI Chat Completions 协议的接口 |
| API Key | 你的模型服务密钥，仅保存在本地 |
| 模型名称 | 推荐 `gpt-4o-mini`（便宜快速）或 `gpt-4o`（更准确）|
| 提取词汇数量 | 建议 20-50 个 |
| 最少词汇数 | 页面词汇少于此数量时不自动标注 |
| 默认显示翻译 | 勾选则直接显示，否则需悬停查看 |
| 自动注解 | 可分别设置中文/英文页面 |
| 网站黑名单 | 每行一个域名，支持通配符 |

## 🔒 隐私与安全

- **数据范围** - 只发送当前页面正文到你配置的 API
- **密钥存储** - API Key 使用浏览器本地存储，不会上传
- **开放接口** - 你完全控制使用哪个模型服务
